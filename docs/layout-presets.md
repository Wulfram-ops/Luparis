# Integrated play workspace

The previous draggable module layout and its presets have been removed. The Play / Jeu tab combines a fixed responsive battle map and a character sheet with persistent resource controls, Actions, Checks, Equipment and Notes sections. Table tools sit below the map in fixed tabs. All original control IDs and delegated game handlers are preserved. GM-only notes are not exposed to players. On narrow screens, the sheet follows the map. Public and second-screen map views remain available, while detachable individual modules are retired. Old layout preferences are ignored; map and character data are not migrated or deleted.
